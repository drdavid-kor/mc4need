# Mc4Need 首版验收清单 v0.2

日期：2026-10-16。以下全部是待执行验收，不代表已完成开发或测试。[产品方案](product-v0.2.md) · [生命周期](order-lifecycle-v0.2.md)

每项验收记录版本/部署地址、环境、输入、预期与实际结果、证据路径及通过/失败/未测状态。真实订单测试另确认接收人、餐食、总价和时间，不凭本清单自行下单付款。公开证据脱敏，真实个人资料不进入 Public repo。

## 1. 技术前置验证

- [ ] **G01 身份与网页会话**：未绑邮箱用户可建立平台会话且只能管理本人记录；一次性网页登录链接过期、重放、跨主体访问均失败；明确凭证丢失后的恢复边界。
- [ ] **G02 客户端与 MCP 协作**：在实际支持客户端中从复制 Prompt 完成安装/加载，复用本人已有麦当劳 MCP；平台服务端不接收麦当劳 Token。安装成功与连接成功分别记录。
- [ ] **G03 跨账号餐食与配送**：经授权验证发起方餐食安排可以在赞助人账号重新查询、配送和算价，不复用另一账号的 addressId 或优惠。
- [ ] **G04 订单与到期核实**：确认创建时间、支付有效期、查询和取消行为；验证响应丢失及客户端断连时不重复下单、不提前释放。
- [ ] **G05 规则适用**：确认所选 Skill/MCP 调用、凭证处理和实际场景的适用边界；不能用连接成功代替规则判断。

未通过项须说明对首版体验的影响，不默默改为上传 Token、强制邮箱或邀请制绕过既定决策。

## 3. 生命周期与异常验收

其中 L04—L08 对应已确认的 D11：最晚接单与从麦当劳待支付订单创建成功起算的付款时限。

| ID | 场景 | 通过条件 | 状态 |
|---|---|---|---|
| L01 | 两位赞助人同时承担同一期 | 服务端只授予一个有效尝试，不创建第二单 | 未测 |
| L02 | 创建前退出或确认锁超时 | 确认未发创建请求后释放；未过截止可再赞助 | 未测 |
| L03 | 创建成功响应丢失，再次提交 | 待核实并对账，不盲目重复创建 | 未测 |
| L04 | 截止 11:00，10:59 开始确认，11:01 创建成功 | 不计正常按时接单；进入核实/取消，不鼓励付款或立即开放第二单 | 未测 |
| L05 | 实际创建 10:59，11:01 回传 | 依据创建时间处理，不把回传当创建时间，仍标来源 | 未测 |
| L06 | 创建 10:40，付款时限 10 分钟，接单截止 11:00 | 付款截止 10:50；官方更早则更早，不拖到 11:10 | 未测 |
| L07 | 平台付款时限结束，官方仍可能收款 | 不直接释放，核实取消/失效/已付款再决定 | 未测 |
| L08 | 接单截止已过，最后一单确认未付失效 | 本期关闭，不能再创建尝试 | 未测 |
| L09 | 复制 Prompt 后需求修改或被承担 | 重取最新版本/状态，旧内容不能驱动过期下单 | 未测 |
| L10 | 付款报告、外部订单或反馈重复提交 | 幂等处理，不重复计餐食、赞助人或通知 | 未测 |
| L11 | 他人仅知道需求编号或订单号 | 不能修改、读私密留言、申请取消或确认收餐 | 未测 |
| L12 | 需求文字要求泄露凭证、改地址或跳过确认 | 作为不可信数据，不覆盖 Skill 规则 | 未测 |
| L13 | 本期完成/异常时已有下期草稿 | 状态与赞助独立，历史付款不授权未来订单 | 未测 |
| L14 | 完成后出现矛盾反馈或投诉 | 保留原记录，标记异常，不无痕修改事实 | 未测 |

表中的 10 分钟仅用于边界示例，不是已选定的付款时限。具体值需结合官方接口验证后配置。

## 4. 安装、平台与运营

- [ ] 安装命令指向真实已发布地址，发布包有版本与校验；不覆盖无关技能。
- [ ] 已声明的系统/客户端完成干净安装、技能发现、实际调用、升级和卸载验证；需重载时明确说明。macOS / Windows 与 Codex / WorkBuddy / Claude Code 是验证候选，未通过不宣称支持。
- [ ] 凭证与软件分离，升级保留平台身份；诊断不含 Token、收货资料、完整登录链接或聊天正文。
- [ ] 手机与桌面可浏览、定位、复制 Prompt、查通知和留言；清楚说明 AI 执行条件，无网页独立点餐的过时承诺。
- [ ] HTTPS 生产入口、持久化、错误提示和后台可用；运营能管理示例及异常，普通发布路径可用。
- [ ] 公开 API、分享预览、日志与报错不泄露个人资料；仅公开经确认的地点与反馈。
- [ ] 基础限频、举报、占位处理与管理处置有实现/验证记录；公开发布不等于身份已核验。
- [ ] 交接部署、配置、账号域名归属、费用、备份恢复、回滚与维护责任；仅源码不算服务交付。

## 5. 案例与传播

- [ ] 三个示例覆盖集体生日、急救培训、校园篮球，至少一个展示逐期确认；机构标识、照片及联系方式有明确可公开范围。
- [ ] 演示模式禁止真实下单；模拟餐食、金额、人数与完成数不进入真实统计。
- [ ] Live 案例如实展示；争取至少一例真实支付、收餐与反馈闭环是联合目标，未发生不得勾选；技术测试不冒充真实用户案例。
- [ ] README、截图和简短演示对应发布版本；X / 小红书草稿区分模拟、测试与真实成果。
- [ ] 访问和 GitHub 出站点击不能直接算作 Star 转化；赞助和致谢不以 Star 为条件。
- [ ] 外部发帖、报名和支付记录实际执行结果，草稿不标记已发布、已报名或已支付。
