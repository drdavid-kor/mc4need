# Mc4Need 项目文档

**Sponsor a meal. Be part of it.**

产品基线 v0.2，当前软件版本 v0.1.1。规格中的选择、代码实现、平台测试与真实交易是不同层次，当前结果以 [验证记录](verification.md) 为准。

| 文件 | 用途 |
|---|---|
| [完成审计](completion-audit.md) | 对照所有原始验收项的证据与缺口 |
| [验证记录](verification.md) | 已测范围、生产检查、安装矩阵、未完成项 |
| [产品方案](product-v0.2.md) | 18 项确认决策、交互与待验证假设 |
| [生命周期](order-lifecycle-v0.2.md) | 期次、赞助尝试、截止、取消和完成规则 |
| [原始验收清单](acceptance-v0.2.md) | 产品基线检查项；不把局部平台测试当作真实订单验证 |
| [交付范围](delivery-scope.md) | 必交项、边界与外部依赖 |
| [实现架构](architecture.md) | 当前安全与状态约束、配置值 |
| [运营交接](operations.md) | 部署、后台、备份、恢复、回滚和邮件配置 |
| [传播草稿](launch-copy.md) | X / 小红书草稿及素材说明，尚未发布 |
| [参赛准备](contest-submission.md) | 参赛文件与提交状态，尚未报名 |

原始附件、历史方案与评估保留在本地，不进入公开仓库。附件内的建议不覆盖后续用户确认的产品决策。
