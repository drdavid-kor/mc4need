# Covers, supporter following and English localization

Software release: v0.2.0. Product update dated 2026-10-18.

## Requester images

Requesters can upload, replace or remove a cover in **My space → Needs I started → Manage cover**, including while a need is still a draft. No upload is required. The browser accepts JPG, PNG and WebP up to 10 MB, converts to a still WebP, resizes the longest edge to 1600 pixels and strips metadata before upload. The stored file is capped at 400,000 bytes. Publication permission is explicit.

The server authorizes the owner, requires permission confirmation and validates the WebP container and allowed chunks. Draft covers are available only through an authenticated owner endpoint. Public delivery checks the need's visibility on every request; hiding a need hides its cover. Removal deletes the stored image and restores the default. Replacing an image changes its image revision without altering an agreed meal or its order state.

One compressed image is stored per need in the project's D1 database. Backups must include the `need_covers` table. The additive migration is `0004_covers.sql`; code rollback may leave the unused table and nullable column in place. Uploads are not committed to Git or included in release archives.

The four built-in defaults depict mainland Chinese classroom birthdays, community first-aid learning, university basketball and a general shared table. They were generated once with Image Generation, optimized as WebP and shipped as static assets. They are labeled as AI illustrations, not real-scene photos. The `other` category has its own general illustration. [Final prompt set](cover-art-prompts.md).

## Supporter entry

The home-page supporter button copies a complete following prompt with one click. A dialog shows what was copied and permits copying again. If the browser denies clipboard access, it exposes selectable text and gives a manual-copy instruction.

The prompt directs the user's AI to establish interests, budget, frequency, timezone and notification channel, query fresh public needs, exclude demos/unavailable/expired needs and suppress repeat notifications. It requires the client's actual persistent scheduler and a confirmed tool result before claiming a task exists. Unsupported clients must explain their limitation. Following requires no McDonald's login and does not authorize claiming, ordering or paying.

The website does not itself schedule notifications. This release tests prompt generation and clipboard behavior; it does not claim universal scheduler compatibility or that a user's reminder has already been created.

## English localization

Chinese and English are selected with the visible language switch; the preference persists. An explicit `?lang=en` or `?lang=zh` takes priority, followed by the saved preference and browser language. The language switch reloads the current route. Navigation, guidance, private-order forms, system notices, error messages, demo stories and AI prompts have English copy. An English installation guide is published.

Mc4Need still serves **mainland China**. English does not imply worldwide delivery. Prices remain CNY; meal and cutoff times use Asia/Shanghai (UTC+8), independent of the viewer's browser timezone. Real user-authored stories, feedback and addresses retain their original text rather than being silently machine-translated.
